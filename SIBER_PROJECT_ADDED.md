## ?? Interview Preparation

### Potential Questions & Answers

**Q: Tell me about your most recent project.**
> "My latest project is SIBER, a real-time balance monitoring system for Bank Sahabat Sampoerna. It uses Playwright to scrape balance data from TEMENOS T24 and Portal BI, then automatically detects discrepancies with a multi-level alert system. I built it using .NET 9.0 with Windows Forms, and it includes features like role-based access control, Google Chat integration, and audio notifications. The system reduced manual checking time from hours to seconds and provides full audit trail for compliance."

**Q: What challenges did you face with web scraping?**
> "The main challenges were session management and anti-bot detection. For Portal BI, I implemented a persistent session that stays logged in across multiple scrapes, while T24 required a stateless approach with fresh login each time. I also had to handle dynamic page loads, implement smart retry logic for session expiry, and add configurable delays to avoid rate limiting. Using Playwright instead of simpler tools like HtmlAgilityPack was crucial for handling JavaScript-heavy banking portals."

**Q: How do you ensure security in banking applications?**
> "For SIBER, I implemented several security layers: SHA256 password hashing using modern .NET 9 APIs, role-based access control with Admin/Viewer roles, full audit logging of all user activities, encrypted SQL connections with TLS, and secure credential storage in the database. All authentication flows are validated, and sensitive operations require proper authorization. The system also tracks session management to prevent unauthorized access."

**Q: Tell me about the architecture decisions in SIBER.**
> "I designed a dual-scraper architecture: ScraperT24 is stateless (login-scrape-logout per cycle) because T24 sessions are unreliable, while ScraperPortal uses session-based scraping (login once, reuse session) for better performance. Both scrapers run in parallel threads to maximize speed. The threshold system supports both percentage and nominal modes, and the alert mechanism is event-driven with configurable audio notifications. I used repository pattern for data access and dependency injection for testability."
